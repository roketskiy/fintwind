## 实施计划

### 1. 移除标题栏入口并建立会话浮层锚点
- 从 `src/app/sidebar.rs` 的 `render_header` 移除现有 `render_background_work_summary`，标题栏保留窗口控制、会话标题和右侧面板按钮，不再显示“环境/后台”入口。
- 在中央会话列的现有 `.relative()` 根容器中加入新的悬浮工具胶囊，挂在标题栏下方的会话内容区域右上角，不参与 transcript 布局、不挤压消息和滚动条。
- 复用现有 `popover`/`ContextMenuHandle`/`MenuAlign::BelowRight`，让浮层具备外部点击关闭、Escape 关闭、焦点转移与恢复、Enter/Space 打开等桌面交互，而不是手写一个无键盘语义的绝对定位弹窗。

### 2. 复用现有行为，组合新的四段内容
在 `src/app/background_work.rs` 中抽出可复用的 Git/后台内容构建逻辑，并新增会话工具胶囊渲染入口。展开面板固定按以下顺序展示四段，空状态也保持顺序和可理解的占位内容：

1. **Git 工具**
   - 更改统计行沿用当前 branch snapshot 缓存，点击打开 `Uncommitted` diff。
   - 当前分支行沿用已有 branch snapshot/branch picker 逻辑，不在 render 中触发 Git I/O。
   - 提交或推送、比较分支继续调用现有 `open_commit_dialog` 和 `set_right_panel_diff_source`，保证原有能力不丢失。
2. **Todo**
   - 将协议已经归类为 `ActivityKind::Plan` 的 `TodoWrite`、`todo_write`、`update_plan` 等活动作为只读 Todo 列表呈现，展示最新标题/详情和完成、进行中、失败状态。
   - 不新增后端协议或第二份 Todo 数据源；对已 hydration 的 transcript 使用轻量显示模型，并在活动更新、会话 hydration、切换会话时更新/失效缓存，避免在每帧行构建器中重复解析原始 JSON。
   - 没有计划活动时显示明确的空状态，并保留键盘可达的区域焦点。
3. **子代理**
   - 复用 `BackgroundWorkRegistry` 中 `BackgroundWorkKind::Subagent` 条目，保持现有排序、状态图标、停止动作和点击后打开右侧 `BackgroundWork` surface 的行为。
4. **后台**
   - 复用 Process/Monitor 条目和现有停止、状态 reconcile、输出刷新链路；点击条目仍切换到对应会话并打开右侧详情。

### 3. 视觉与交互处理
- 收起态采用示意图风格的紧凑胶囊：显示 Git 图标/更改统计，固定尺寸、`rounded_full`、raised surface、边框和轻微阴影；展开态保持稳定宽度和最大高度，内容超出时只滚动浮层内容。
- 使用现有主题语义 token：`theme.raised`、`theme.border_strong`、`theme.text*`，并以现有 `Theme::accent` 作为 `#D97757` 的点缀、打开态、焦点环和进行中状态颜色；增删数字继续使用 `success`/`danger` 表达数据语义，不把状态仅编码为颜色。
- 为触发器、四个区域、重复行和停止按钮使用稳定的 domain-based `ElementId`；补齐 hover、pressed、disabled、focus-visible 和 loading/empty 状态，避免胶囊展开时布局跳动。
- 维持现有浮层优先级和窗口边缘碰撞处理，窄窗口下由 popover 的 viewport clamp 保证面板不会跑出窗口。

### 4. 测试与验证
- 为 Todo/Plan 显示模型补充纯函数测试：活动提取、最新状态覆盖、空状态以及四段排序/分类。
- 保留并运行现有后台 registry 测试，确认拆分渲染 helper 不改变停止乐观更新、reconcile 丢失、输出缓存和子代理保留逻辑。
- 修改后等待仓库已有 `bun ./scripts/dev.ts` watcher 完成重建并验证新启动的 debug app；不启动第二个 watcher、不手动退出应用，也不做未请求的截图视觉测试。
- 运行聚焦 Rust 测试与 workspace `cargo check`，最后检查工作树只包含本次 UI 改动和原有未跟踪文件 `scoop_exit.txt`。
