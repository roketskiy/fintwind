# Security Policy

## Supported Versions

Only the latest release of Fintwind receives security fixes. Download the
newest release from https://fintwind.xyz or the GitHub releases page.

## Reporting a Vulnerability

Please use GitHub private vulnerability reporting:
https://github.com/roketskiy/fintwind/security/advisories/new

Please don't open a public issue for anything you believe is
exploitable before it has been fixed. Include reproduction steps and
the Fintwind version shown at the bottom of Settings in the app you tested.
