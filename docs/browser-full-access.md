# 内置浏览器完全访问

## 已确认的行为

- 浏览器工具启用时，本机当前会话的所有浏览器标签都可以被工具使用，手动打开与工具打开的标签没有权限区别。
- 计划和构建模式，以及会话的其他访问模式，均不对浏览器操作逐次审批。
- 工具可以使用密码框、打开本机文件页面；快照可以包含密码、隐藏字段和其他表单值。
- 页面仍属于其会话。切换会话、运行实例更换、连接中断或请求取消时，旧请求不能转到其他会话或迟到执行。
- 浏览器工具的启用开关仍控制工具是否可用；它不是逐页授权。
- 为限制资源占用，每个连接最多同时发布 256 个标签；单次返回内容和元素数量仍有上限。工具支持的操作仍以现有原生适配器为准，例如不等同于任意 CDP 接口。
- 原生页面操作一次只执行一项，避免并行切换标签时操作错页；繁忙时明确拒绝且不发出新动作。

## 实现前列出的失败模式

- 只修改工具说明，实际打开、点击或截图仍等待用户审批。
- 计划模式、模式切换或人工打开的标签仍被错误地排除。
- 当前会话的后台标签不可操作，或者操作了另一个会话中同名的标签。
- 页面加载完成、创建或恢复会话后，已有标签没有被及时发布。
- 导航、同文档 URL 更改或加载失败使权限永久丢失，或旧元素引用指向新文档。
- 会话切换、运行实例替换或断线后，旧的页面标识继续跨会话生效。
- 操作取消或页面关闭后，等待页面可见的请求仍继续执行；不确定的副作用被自动重试。
- 密码字段仍不可输入，本机文件 URL 在插件、协议、broker 或原生页面层被拒绝，快照仍遗漏用户明确要求开放的字段。
- 浏览器状态显示为需要共享或审批，但实际上没有对应步骤。
- 实验使用日常浏览器 profile、真实账号、真实数据目录，或清理了非本次创建的进程。

## 验证边界

优先验证真实会话绑定、页面路由、取消、URL 和快照行为。原生 WebView2 验证必须使用独立 profile、独立数据目录、环境白名单和能够证明子进程归属的边界。不能满足这些条件时不运行该验证，不把模拟宿主或编译成功表述为完整 GUI 验收。

本次按用户要求不执行构建检查。旧 `browser:collaboration` runner 尚未证明环境白名单和 Windows 子进程容纳边界，不能直接用于本次验证；新增的端到端检查尚未执行。
