# 浏览器与 AI 协作：手工验收

完整应用的最后实际测试由用户自行执行。本轮不新增产品测试控制入口、不启动
正常应用或 watcher、不做截图测试。原生适配器使用独立的现有 PoC 宿主验证，
不是完整产品界面验收。核心工具链、原生适配器和恢复流程的自动验证
记录见 [browser-tools.md](browser-tools.md)，不能代替下列手工界面验收。

## 准备

1. 使用本次构建，`fintwind.exe` 与 `fintwind-daemon.exe` 放在同一目录。
   普通旧构建不会因当前仓库源码已修改而自动获得新功能。
   本轮提供的是正常开发构建（不启用 PoC 或产品验收 feature）：
   `target/debug/fintwind.exe` 与 `target/debug/fintwind-daemon.exe`。
   手工打开前者即可；不会替换已安装程序，也不会自动停止正在运行的安装版。
   开发版 Fintwind 使用仓库 `temp/` 的任务 / 界面数据，与正式版目录不同；
   OpenCode 的账号配置仍按正常产品流程读取，不将开发数据隔离误称为账号隔离。
2. 本机启动 Fintwind，使用应用管理的本机 daemon；外部 / 远程 daemon 模式
   不显示页面共享入口。OpenCode 本轮已验证版本为 `v2.0.16`。
3. 新建测试会话，选择「完全访问」和「构建」，直接要求 AI 在应用内浏览器
   打开网址。无需先手动打开或共享页面；AI 打开的是本会话的专用自动化标签。
   手动已有标签仍须点击共享才能交给 AI。
4. 打开适合分享的本机测试页面，避免真实账号、密码、付款或生产业务数据。
   同一应用的浏览器标签共用 profile；新标签不等于账号 / Cookie 隔离。

可以先用一个不涉及账号的请求检查最基础路径：

> 在应用内浏览器打开 https://fintwind.xyz，告诉我页面标题，再通过页面中的
> 一个链接导航并报告新页面标题。不要用抓网页源码代替内置浏览器。

预期先调用 `fintwind_browser_open`，随后观察页面并使用返回的元素引用。
不会因为页面列表为空而要求连接另一个 OpenCode 桌面应用。如果此前手动
接管或连接中断，旧授权不会自己恢复；需要明确重新共享测试标签，或重新选择
完全访问以授权新的打开能力，不要求重启整个应用。

## 优先检查项

| 操作 | 应看到的结果 |
| --- | --- |
| 「完全访问」下，让 AI 打开本机测试网址，再连续点击、输入、导航 | 应显示真实内置浏览器；不要求逐次审批，不要求每次导航重新共享；使用同一标签完成任务。 |
| 未共享已有手动标签时，让 AI 列出可访问页面 | 不能看到其他未共享手动标签；AI 自己打开的本会话自动化标签可以读取和操作。 |
| 非完全访问模式，手动打开并共享测试页面，再发起动作 | 保留「允许这一次」「拒绝」；等待时不执行，拒绝后不执行。完全访问与监督模式不是同一种行为。 |
| 在当前文档内滚动、点击控件、选中文字或把键盘焦点交给原生页面 | 共享保持，不暂停打开能力。完全访问下 AI 能继续操作；监督模式仍需逐次批准，跨导航仍按原规则重新共享。 |
| 点击地址栏旁「已共享」停止按钮；或打开过程中点击「正在打开」停止按钮 | 共享 / 打开撤销、待审批操作结束，旧授权不能再执行，也不能开替代标签绕过停止；之后必须重新共享或明确恢复访问设置。 |
| 切换会话或从完全访问切到监督 / 计划模式 | 旧自动权限撤销；不能通过旧页面授权连续操作。自动化导航保留标签权限，但旧文档的元素引用失效。 |
| 使用 Tab、Enter / Space 操作审批控件；焦点在审批栏内按 Escape | 键盘能操作控件，有可见焦点；Escape 拒绝待审批动作。 |
| 审批结束时页面处于加载或错误状态，共享按钮不可用 | 焦点不会回到禁用的共享按钮；仍能用键盘继续浏览器操作。 |
| 页面持续自行滚动时让 AI 点击目标 | 超过有界等待后明确拒绝，不继续点击、不自动重试；页面停止后重新观察再操作。 |

还可检查：runtime 更换时共享状态撤销且提示可读；本机 daemon 的连接中断后
由 supervisor 恢复连接，但不自动恢复共享、不自动重发页面动作。只针对自己
的测试实例制造故障，不停止正在处理日常任务的 daemon 或全局 OpenCode 服务。

## 预期边界

- 完全访问允许本会话连续操作；其他模式保留逐次审批。观察快照不要求批准。
- 支持主文档的观察所得元素引用、普通文本输入、HTTP(S) 导航和有界滚动；
  不支持 iframe、密码输入、任意脚本或任意 CDP。不宣称达到 Playwright 全部能力。
- 子代理不隐式继承父会话的共享授权。
- 已发出的单次操作可能已经发生，取消不是回滚；结果不确定时重新观察，
  不自动重复点击或输入。
- 密码 / 隐藏字段 / Cookie 不导出，但页面中可见的正文与账号信息仍属于
  共享内容，不承诺自动识别网页中的全部机密。

发现问题时记录：本次应用构建、OpenCode 版本、操作顺序、是否已共享、审批
选择，以及实际结果。最后完整应用验收尚未代用户执行，不标为已通过。
