# /btw 说明

`/btw <问题>` 让 OpenCode 用当前会话已确定的上下文和已选模型给一次性回答。
它不接管主任务、不排队、不产生回合、不记入任务历史；原生右侧面板为每个会话
保留一份临时回答。

## 使用

开始对话后，在输入框输入 `/btw <问题>`，用回车、发送按钮或引导快捷键发送。
侧栏回答在原生 `/btw` 标签页打开，主任务运行时也可提问。新问题替换本会话
上一次侧栏回答，不形成多轮对话。

面板支持 Markdown 选中与滚动、复制、重试和取消。切换会话会取消未完成的提问，
但保留已完成的回答；关闭标签页清除其问答；面板内按 Escape 关闭并回到输入框。
应用重启后侧栏回答不保留。

空问题和新附件会被拒绝且不丢失输入。更换模型/变体后，先发送一条普通消息使新
选择在 OpenCode 生效，侧栏生成不会自行切换原生会话的模型。提交成功的提问消耗
一次真实模型调用。
