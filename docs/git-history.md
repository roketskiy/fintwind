# Git 历史面板

历史面板参考 Ely 的 CommitGraph（其源码中对应 `CommitList::graph()`），
使用真实父提交绘制分支轨道、分叉和合并节点，没有引入 Ely 运行时依赖。

## 展示与操作

- 提交标题是第一层信息，分支与标签使用紧凑徽标；第二行显示短哈希、作者和时间。
- 左侧彩色轨道表示父提交关系；合并提交用空心节点，HEAD 有额外光环。
  连线结构和节点形状承担含义，不仅依赖颜色。
- 当前历史顶部提交的第一父提交链固定在主轨道，支线在共同祖先节点汇入，
  不因支线先访问共同祖先而让主线换色。颜色代表轨道，不是 Git 分支的固有属性。
- 保留 HEAD / 指定分支筛选，显示所选引用可达的历史，不自动改成所有分支。
- 点击行只选中提交，不再复制；上下方向键移动选中项，Home / End 跳到首尾。
  详情里的 SHA 旁有复制按钮，支持 Tab 聚焦和 Enter / Space 激活。
  刷新按钮也支持 Enter / Space。
- 选中行后，下方显示完整标题、哈希、变更文件数、增加和删除行数、作者和全部引用。Tab 可聚焦详情区域，
  方向键滚动、Home / End 跳到首尾，Escape 返回列表；完整名称不依赖悬停。
  详情区保留固定高度，首次选择不会缩小列表视口并遮住末尾选中行。
- 每次最多读取 500 条。窗口外的父提交保留向下延伸的轨道，不伪造根节点。

## 性能说明

历史读取与轨道布局在后台完成并缓存，渲染只读快照；列表虚拟化，每次只绘制
可见行。无变化的刷新复用快照，不重置滚动位置；新提交到达时按原提交哈希恢复
浏览锚点和选中项。变更量仅在选中提交后于后台读取并缓存：合并提交相对第一父
提交，根提交相对空树；二进制文件计入文件数但不计行数。

轨道分配算法改编自 Ely 的 `src/git/graph.rs`，许可见 `licenses/ely-gpui-components-MIT.txt`。
