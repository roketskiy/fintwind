# 移动端远控：隐私与恢复

本说明适用于无账号、逐设备配对的第一阶段。上线检查必须核对实现与部署；
本文件不表示所有检查已经通过，也不替代密码协议及实现审查。

## 哪些内容会离开电脑

手机可以管理已配对电脑的全部会话与历史，并按需查看已有项目的文件、diff 和
任务输出。会话指令可以让 agent 按本机权限执行工具；“只读工作区”不代表手机
没有控制权，也不代表 agent 被限制为只读。

业务消息在电脑与手机之间端到端加密。可信端点下，中继和网络代理看到的是
密文以及连接与路由元数据，不应持有端点私钥或业务明文。手机在解密后能够看到
内容；不要把不可信浏览器或他人的设备配对为控制端。

## 信任边界

| 对象 | 可见信息与权限 |
| --- | --- |
| 电脑端 | 会话、工具权限、工作区、设备授权及执行结果，是唯一执行授权源 |
| 已配对手机 | 经授权返回的会话与工作区内容，以及控制与逐次审批能力 |
| 中继运维方 | 端点公钥、配对关系、连接时间、来源 IP、路由与流量大小；可阻断投递 |
| Cloudflare | TLS 终结点的外层帧及连接元数据，不持有业务解密密钥 |
| PWA 发布方 | 控制手机执行的代码，属于高权限信任边界；恶意更新可读取解密内容或代操作 |
| 浏览器与扩展 | 可能访问页面、浏览器配置文件或调用同源密钥，端到端加密不能防端点失陷 |

PWA 发布流水线、来源和发布凭据必须独立于中继运维。仅使用不同路径、使用
TLS 或设置 CSP 都不等于发布隔离。隔离未落实时不得宣称中继运营方无法通过
替换手机代码取得内容。

第一阶段无推送通道。后续推送必须单独披露第三方可见元数据，不带会话正文、
命令、路径或可以直接执行审批的凭据。

## 存储与清理

- 会话、文件、输出与待提交输入仅存手机内存，不写业务数据库或浏览器缓存。
- 待提交输入有上限及到期时间，重载或关闭会丢弃，不能承诺跨重载投递。
- 设备身份是独立存储项；退出连接不等于撤销电脑授权，清除身份也不等于所有
  电脑已撤销。界面与文档必须区分这些动作。
- Service Worker 只允许缓存静态应用壳，不缓存业务响应。敏感响应使用 no-store。
- 中继身份库只保存公钥与配对关系；密文投递队列有界、仅在内存中，重启丢弃。
- 审计与错误日志不得包含指令、正文、nonce、私钥、认证签名或完整访问 URL。
- 脱敏只能降低意外泄漏风险，不能保证工具输出绝不含秘密。

### 身份密钥保护的实际边界

Windows 电脑身份由当前用户的 DPAPI 保护。密封记录损坏、换 Windows 用户或
换机器后无法解密时，不自动生成替代 host 身份，也不自动信任新指纹。旧明文
迁移须完成密封写入、解密读回与身份比对后，才可删除原记录。

手机使用 IndexedDB 中不可导出的 Web Crypto AES-GCM 包装密钥，保护持久化的
Rust 身份记录。这不代表 Noise 私钥在所有阶段都不可导出：连接时原始身份和
私钥仍需在 WASM 内存中使用，受页面、浏览器与扩展的高权限信任边界约束。
不能把包装密钥不可导出宣传为能防止恶意页面读取或使用设备身份。

项目文件过滤只是一道补充限制。已知凭据和私有配置路径禁止读取，打开后的
实际链接目标也须检查；但普通源文件、工具输出或用户自行命名的文件仍可能含
秘密，不承诺仅凭文件名就能识别全部秘密。

身份元数据、审计、代理日志及备份的保留期限、大小上限、访问权限与删除延迟
必须在外部试用前填写到部署记录并验证。未配置轮转或期限，不算上线检查通过。

## 设备丢失或页面失陷

1. 在每台已配对电脑的本机设备页撤销该设备；本机撤销才是可靠执行边界。
2. 同时撤销该电脑在中继的配对关系并断开通道。中继成功不能替代本机确认。
3. 不可达的电脑记为撤销待确认；不要显示已全部撤销。已执行副作用不会回滚。
4. 在手机清除站点数据，注销旧 Service Worker，关闭页面并检查已安装 PWA。
5. 修复并核验发布产物后，创建新设备身份并在每台电脑重新核对校验码、确认授权。

受影响设备清理后，不恢复旧身份或自动重新批准。电脑重装或丢失密钥时也使用
新 host 身份，所有设备重新配对。

## 发布与回滚检查

- 固定依赖锁文件，校验 WASM 与 JavaScript glue 来自同一构建。
- 使用不可变构建目录与原子发布，保留已知可用版本；失败不删除当前可用文件。
- 回滚保持明确的协议版本检查，不以明文回退、接受新指纹或放宽授权恢复服务。
- 验证 HTML、WASM、脚本、manifest 与 Service Worker 的缓存策略；检查旧 worker
  不会混用新旧协议或再次缓存业务内容。
- 用合成身份与隔离工作区验证真实中继链路，检查授权、撤销、错误与清理路径。
- 留存版本、检查命令与脱敏结果。构建成功或一次网络请求成功不代表远控已验收。
