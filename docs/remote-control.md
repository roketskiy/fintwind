# 手机远控设计

手机网页控制正在运行的 Fintwind 桌面。桌面关闭或用户停止远控后，本次配对失效。手机不运行 Agent，也不直接连接 daemon。

## 使用范围

手机可以切换开启远控时桌面已登记的工作区，查看会话、新建会话、发送消息、停止任务、处理权限审批和回答问题。手机不能浏览任意目录、新增工作区、配置 SSH 连接或修改全局设置。

会话列表只包含最近更新时间处于过去 72 小时内的会话。读取会话和执行操作时也检查这一条件，不能通过已知会话 ID 读取更早的内容。新建会话使用桌面现有的创建和提交路径。

授权以本次开启时的工作区 ID 集合为边界。随后在这些工作区中新建的会话可以访问。新登记的工作区需要停止并重新开启远控后才能访问。

## 状态和操作归属

桌面保留会话状态和操作分发权。手机只提交受限业务操作，不提交 daemon 命令。远控和本地操作复用相同的提交、停止、审批和问答实现。

网络连接、加密、重连和中继帧处理在后台执行。渲染只读取内存中的连接状态和配对图像。手机快照有大小限制，不包含完整会话对象、daemon token、环境变量或附件内容。

## 中继部署

新中继部署在 UCloud 的独立服务中。域名为 `fintwind-mobile.roketskiy.top`。保留服务器现有的 `fintwind-relay.service`、`relay.fintwind.xyz` 站点和 `fintwind.roketskiy.top` DNS 记录。

使用固定提交的 Alma Relay Node 版，中继源码和许可证见 `deploy/remote-control/UPSTREAM.md`。中继只绑定 loopback，由现有 Caddy 提供 HTTPS。Cloudflare DNS 通过 `cf` CLI 管理。

共享中继允许所有 Fintwind 安装用户自动接入。桌面使用独立安装身份签名领取短期注册凭证，中继按安装身份、来源 IP 和全局限额准入。安装身份不是人的身份，不能阻止重装产生新身份。详细协议与限制见 `remote-multiuser.md`。

连接认证不增加用户步骤。用户只需开启远控并扫码或打开配对链接，不输入账号、密码或 token。桌面在后台创建并保存安装密钥，Windows 使用当前用户 DPAPI 保护。注册凭证只缓存在内存，不进入 Git、二维码或手机网页，也不代替手机配对授权。手机通过配对链接自动取得本次连接密钥。Agent 的操作审批不属于连接认证，仍需用户明确处理。

网页发布源属于信任边界。若源站被控制，攻击者可以替换网页脚本并窃取配对密钥，端到端加密不能防止这种攻击。中继服务使用独立低权限账户，不能修改由 root 持有的网页文件。本协议不提供前向保密。

用户要求不执行任何测试。此次不运行单元测试、端到端测试、视觉测试、接口测试或远控功能探测。构建与代码审查不能证明手机远控可以正常工作。
