# 手机远控说明

手机网页控制正在运行的 Fintwind 桌面。桌面关闭或用户停止远控后，本次配对失效。手机不运行 Agent，也不直接连接 daemon。

## 开启与配对

在桌面侧边栏开启远控后，用手机扫码或打开配对链接。无需输入账号、密码或 token，配对密钥由配对链接自动下发。

关闭远控、退出桌面或重新配对后，旧授权失效。

## 手机可以做什么

- 切换开启远控时桌面已登记的工作区。
- 查看会话、新建会话、发送消息（含图片和小文件附件）。
- 停止任务、处理权限审批、回答问题。
- 桌面通告 Goal 能力时，可查看目标并暂停、恢复与清除。

手机不能浏览任意目录、新增工作区、配置 SSH 连接或修改全局设置。

## 可见范围与授权边界

- 会话列表只包含最近更新时间处于过去 72 小时内的会话；读取与操作同样受该条件约束，不能通过已知会话 ID 读取更早的内容。
- 授权以本次开启时的工作区 ID 集合为边界；随后在这些工作区中新建的会话可以访问，新登记的工作区需要停止并重新开启远控后才能访问。
- 新建会话使用桌面现有的创建和提交路径；远控与本地操作复用相同的提交、停止、审批和问答实现。

## 安全说明

- 连接使用端到端加密；桌面保留会话状态与操作分发权，手机只提交受限业务操作，不提交 daemon 命令。
- 手机快照有大小限制，不包含完整会话对象、daemon token、环境变量或附件内容。
- 网页发布源属于信任边界：若源站被控制，攻击者可替换网页脚本并窃取配对密钥，端到端加密不能防止这种攻击。

中继部署与运维见仓库 `deploy/remote-control/` 目录。
