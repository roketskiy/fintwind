# 公开中继接入

本轮面向所有 Fintwind 安装用户，允许不同用户通过同一个中继控制各自电脑。手机仍只需扫码，桌面不显示账号、密码或 token 输入。

## 边界

安装身份不是人的身份。匿名自动接入无法阻止一个人重装或伪造多份安装。每安装限额必须配合来源 IP 和全局限额。此轮不增加账号系统，不支持多人共同操作同一桌面，也不承诺经过测量的并发容量。

保持已有约束。每台桌面最多一个手机连接，桌面退出撤销本次配对，手机只能访问开启时登记的工作区，以及最近更新时间在过去 72 小时内的会话。

## 交付单位

1. 自动安装身份与短期注册凭证。客户端不再依赖管理员手动分发共享注册密钥。
2. 中继按安装身份、来源 IP 和全局资源限额准入，禁止不同身份抢占同一路由。
3. 只读快照增加内容版本。内容未变时返回小响应，不重复传输完整对话。
4. 独立中继升级脚本保留旧版备份和回滚路径，不修改其他服务或域名。

代码检查只包括编译、语法和静态审查。用户禁止所有测试，不运行接口探测、浏览器、负载测试或功能测试。最终由 Muse Spark 1.3 Contributor 审查。不得使用 Luna。

## 自动凭证协议

安装身份采用 Ed25519 公钥，身份 ID 是原始 32 字节公钥的 SHA256 小写十六进制值。本机私钥独立于手机配对密钥、中继签名密钥和 daemon token，永不上传。每次需要注册凭证时在后台执行挑战签名。

所有端点固定在 `https://fintwind-mobile.roketskiy.top`，不跟随重定向。JSON 字段采用 camelCase，base64url 不带填充且必须是标准编码。

1. `POST /v1/admission/challenge` 接收 `{publicKey}`。公钥为 32 字节。响应 `{nonce,expiresAt}`。nonce 为随机 32 字节，绑定此公钥和可信来源 IP，60 秒内有效，限用一次。
2. 客户端签名的 UTF-8 文本为 `fintwind.relay.admission.v1\nhttps://fintwind-mobile.roketskiy.top\nNONCE\nPUBLIC_KEY`，没有末尾换行。
3. `POST /v1/admission/token` 接收 `{publicKey,nonce,signature}`。Ed25519 签名为 64 字节。响应 `{token,expiresAt,installationId}`。
4. token 是 HS256 JWT，`aud` 为 `alma-relay`，`iss` 为 `fintwind-relay`，`sub` 为安装身份 ID，含整数 `iat` 和 `exp`，有效期 24 小时。客户端仅在内存缓存，过期前五分钟重新签发。连接到期时关闭并自动重新注册，配对链接不变。

只有中继持有 JWT 签名密钥。所有安装客户端使用自己的私钥申请 token，不读取或分发共享注册密钥。旧的 `remote-control.json` 可保留，但其中 `registration_key` 不再被新客户端使用。关闭公开接入时，中继必须拒绝新挑战，而不是退化为无认证开放服务。

为已安装的个人客户端保留一次七天迁移窗口。服务器仅在显式配置 `LEGACY_REGISTRATION_KEY` 且未到 `LEGACY_REGISTRATION_UNTIL` 时接受旧凭证，以 `legacy-personal` 身份占用一个配额。新客户端不能回退到此方式。迁移截止不因服务器重启延长。

首次使用时创建本机安装密钥。Windows 使用当前用户 DPAPI 保护，Unix 使用仅用户可读写文件。现存密钥文件损坏时报告错误，不自动重置身份绕过吊销。本机多个启动并发创建时应读取成功落盘的唯一身份。

## 服务器边界

最初全局最多 32 个桌面、每安装最多 1 个桌面、每可信来源 IP 最多 8 个桌面。这些是资源保护配置，不是容量测试结果。保持单桌面一个手机，限制帧大小、预认证连接、挑战表大小、签名请求频率、消息速率和字节速率。

来源 IP 只在直接上游为 loopback Caddy 时读取，Caddy 显式覆盖 `X-Forwarded-For`，不能信任公网客户端自行填写的转发头。不同安装身份不能替换同一路由。所有限额由服务端执行，不依赖客户端自律。

管理员通过服务器本地 CLI 更新 root 持有的吊销文件。中继定期重新读取并关闭已吊销身份的活动连接。配置缺失、损坏或签名密钥无效时拒绝接入，不开放匿名连接。不提供公网管理端点。

## 条件快照

只读请求可以携带顶层 `ifRevision`。服务端仍执行原命令的工作区、会话时间窗口和状态检查，然后计算响应内容版本。若内容版本相同，返回 `{notModified:true,revision}`。版本不同时返回原响应数据并添加 `revision`。

手机只在当前标签页内存缓存有限个只读响应。缓存必须按配对路由和资源区分，不能用于跳过服务器权限校验。重新配对时清空缓存。修改命令不缓存，不自动重试。此轮减少不变快照的传输，不声称已实现流式增量协议或已测量带宽收益。
