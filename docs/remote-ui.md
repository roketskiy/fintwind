# 手机远控界面改造

## 已确认范围

用户要求“使用 Shadcn 组件构建完整的网页”。会话列表与对话为两个独立页面。最新反馈要求紧凑、清晰的信息层级，Composer 与桌面基本对等，可发图片和小文件；工具只需名称和运行状态，不传正文。桌面只改手机远控设置页与远控投影、命令，不改整个设置框架。不增加文件管理或终端。

移动端采用 React、TypeScript、Vite 与官方 shadcn/ui Base UI Maia 组件。构建为静态文件，继续适配现有 Caddy 和加密 WebSocket。无 SSR，无新增网页后端，无第三方内容服务。

## 页面与状态

会话列表包括工作区选择、搜索、按日期分组的最近会话，以及新建会话。显示真实标题、更新时间和状态，不放演示数据。对话页显示 Markdown、可复制代码块、原文用户消息、审批、问答与固定输入区。返回列表保留滚动位置。草稿按会话隔离，只保存在内存。

对话按桌面消息与 transcript block 顺序投影，连续工具及思考用 shadcn Trace 分组。思考折叠，工具仅显示名称与完成、进行中、失败状态，不投影参数、输出或详情。新桌面通过 features 声明能力；旧桌面继续使用正文协议，网页不发送未知命令。

Composer 提供真实模型选择、Build/Plan、思考强度、已登记命令、展开编辑、停止、运行中追加排队、附件选择与粘贴图片。附件单个 2 MiB、最多 8 个、合计 8 MiB；通过 64 KiB base64 分片在现有加密通道传输。桌面后台导入 daemon 附件存储，发送只接受本次配对、同一会话生成的附件 ID，不接受手机传入本地路径。上传及修改不自动重试。未提交上传有数量、大小与十分钟期限，关闭配对释放内存；已导入未引用文件由 daemon 既有清理策略管理。

打开对话直接读取 getSession，不再等待工作区和会话列表。Caddy 压缩静态响应，带 hash 的 assets 使用长期缓存，HTML 仍禁止缓存。未做网络速度实测，不声称实测加速。

明确处理未配对、初次连接、重连、离线、空列表、加载、会话不可用、操作失败和操作待确认状态。断线时不把修改操作自动重发。连接状态不等于桌面在线状态，不编造设备名称或型号。

手机布局适配安全区域和软键盘，保留浏览器缩放能力。点击区域不小于 44 像素。支持系统深浅色和减弱动态效果。弹层有标题，表单有标签，导航和操作可用键盘执行。

桌面页读取现有 RemoteUiStatus，不另建业务状态。保留正常页边距和约 560 像素内容宽度，标题右侧使用现有开关。配对卡突出状态与二维码，只保留复制配对链接、重新配对两个操作。关闭和重新配对继续使用原有撤销流程。

桌面手机远控入口移至固定导航栏的帮助入口上方，使用本地 Lucide smartphone 图标；设置分类列表不再重复显示入口。远控页不占用设置第二栏，键盘可以聚焦并用 Enter/Space 打开。

## 边界

沿用 `remote-control-protocol.md` 与 `remote-multiuser.md`。界面不能接触私钥或 daemon token。HTML 和远程图片不作为助手内容执行或加载。所有认证对用户隐藏。

用户已明确“改完后部署，我要看效果”。构建、静态审查后使用独立前端发布脚本部署，只重载 Caddy、不重启中继，保留旧版与回滚。同步构建新版桌面产物；工具、思考、Composer 配置与附件需要更新桌面并重新配对。不启动 dev watcher，不运行任何测试。仅允许安装依赖、生产构建、类型检查、语法检查、静态审查、部署哈希与服务状态核对。用户此前要求使用 Muse 审查，不使用 Luna。
