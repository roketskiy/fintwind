---
title: Keep a task on course
description: Queue the next step, steer the current turn, or stop cleanly.
---

You can keep writing while an agent is working. Choose whether the message belongs in the current turn or after it.

## Queue a follow-up

Press Return while the agent is working. The message appears above the composer and sends after the current turn settles.

Use this for the next distinct step:

> Once the tests pass, update the release notes.

Queued messages send one at a time. You can move one back into the composer to edit it, or remove it before it sends.

## Steer the running turn

Press `⌘↩` to deliver the message to the turn already in progress.

Use steering to correct an assumption, narrow the scope, or provide missing context:

> Keep the public API unchanged; only adjust the internal call site.

If the active agent cannot accept steering at that moment, Waku keeps the message and queues it as a follow-up instead.

## Stop the turn

Press Escape to stop the active turn. The task and partial transcript remain available, so you can inspect what happened and send a revised request.

<Callout type="idea" title="A simple rule">
  Steer when the instruction changes work happening now. Queue when it describes what should happen next.
</Callout>
