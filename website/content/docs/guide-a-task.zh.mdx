---
title: 调整进行中的任务
description: 排队发送下一步、补充当前任务，或干净地停止执行。
---

智能体工作时，你仍可继续输入。只需决定这条消息应该加入当前任务，还是在它完成后再发送。

## 排队发送后续消息

智能体工作时按 Return。消息会出现在输入框上方，并在当前任务结束后发送。

这种方式适合安排下一个独立步骤：

> 测试通过后，再更新发布说明。

后续消息会逐条发送。发送前，可将某条消息移回输入框编辑，或直接移除。

## 补充当前任务

按 `⌘↩` 将消息直接发给正在进行的任务。

当你需要纠正假设、缩小范围或补充缺失上下文时，使用这种方式：

> 保持公开 API 不变，只调整内部调用位置。

如果当前智能体暂时无法接收补充指示，Waku 会保留消息，并自动改为后续消息。

## 停止任务

按 Escape 停止当前任务。任务和已产生的记录会保留，你可以检查已完成的工作，然后发送修订后的请求。

<Callout type="idea" title="一个简单的判断方法">
  如果指示会改变当前正在执行的工作，就补充当前任务；如果它描述的是下一步，就排队发送。
</Callout>
