## The everyday loop

<Steps>
  <Step>
    ### Open a project

    Add a folder with `⌘O`, or choose **Don't work in a project** for a task that does not need repository context.
  </Step>
  <Step>
    ### Pick how the agent should work

    Choose a model, **Build** or **Plan**, an access level, and either the local checkout or a new worktree.
  </Step>
  <Step>
    ### Send, guide, and review

    Give the agent a clear outcome. Queue follow-ups or steer while it works, then review the resulting changes before moving on.
  </Step>
</Steps>

<Callout title="Your existing agent setup still applies">
  Waku uses each agent's existing sign-in, subscription, models, and usage limits. You do not need a Waku account or a second set of API keys.
</Callout>
