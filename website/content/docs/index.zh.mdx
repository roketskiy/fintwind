## 日常工作流程

<Steps>
  <Step>
    ### 打开项目

    按 `⌘O` 添加文件夹。如果任务不需要项目上下文，也可选择 **不使用项目**。
  </Step>
  <Step>
    ### 选择智能体的工作方式

    选择模型、**构建**或 **计划**、访问权限，以及本地检出或新工作树。
  </Step>
  <Step>
    ### 发送、调整、审阅

    清楚说明目标。智能体工作时，可排队发送后续消息或补充指示；完成后再审阅更改。
  </Step>
</Steps>

<Callout title="继续使用现有的智能体配置">
  Waku 会沿用各智能体的登录状态、订阅、模型和用量限制。无需注册 Waku 账户，也无需另外准备一套 API 密钥。
</Callout>
