## Shortcuts

| Action | Shortcut |
| --- | --- |
| New task | `⌘N` |
| Add project | `⌘O` |
| Command palette and task search | `⌘K` |
| Focus the composer | `⌘L` |
| Choose a model | `⌘/` |
| Show or hide the sidebar | `⌘B` |
| Show or hide the right panel | `⌘⇧B` |
| Open usage | `⌘U` |
| Open Settings | `⌘,` |
| Stop the active turn | `Escape` |
| Queue while an agent works | `Return` |
| Steer the active turn | `⌘Return` |

Use `⌘[` and `⌘]` to move backward and forward through recently viewed tasks.

## An agent is not detected

1. Confirm its command-line app opens and is signed in from Terminal.
2. Open **Settings → Providers** and recheck it.
3. If it lives outside the usual locations, set **Binary path** to the executable and press Return.

## A model is missing

Refresh the agent in **Settings → Providers**. Model availability comes from the installed agent and the account signed into it. If the model is absent there too, update or reconfigure that agent first.

## Revert is unavailable

Stop the running turn and make sure the task belongs to a Git project. **Revert to here** is shown only when the selected agent can safely roll back that point in its conversation. **Fork task** remains the non-destructive alternative.

## Change the language or theme

Open **Settings → Appearance** to choose English, Simplified Chinese, System, Light, or Dark. The docs language switch is in the sidebar footer.
