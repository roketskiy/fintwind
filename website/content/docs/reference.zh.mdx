## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 新建任务 | `⌘N` |
| 添加项目 | `⌘O` |
| 命令面板与任务搜索 | `⌘K` |
| 聚焦输入框 | `⌘L` |
| 选择模型 | `⌘/` |
| 显示或隐藏侧边栏 | `⌘B` |
| 显示或隐藏右侧面板 | `⌘⇧B` |
| 打开用量 | `⌘U` |
| 打开设置 | `⌘,` |
| 停止当前任务 | `Escape` |
| 智能体工作时排队发送 | `Return` |
| 补充当前任务 | `⌘Return` |

按 `⌘[` 和 `⌘]` 可在最近查看过的任务之间后退或前进。

## 未识别到智能体

1. 确认它的命令行程序可以在终端中打开，且已完成登录。
2. 打开 **设置 → 模型服务商**，然后重新检查。
3. 如果程序不在常见位置，请将 **可执行文件路径** 指向该程序，并按 Return 应用。

## 缺少某个模型

在 **设置 → 模型服务商** 中刷新对应智能体。可用模型取决于已安装的智能体和当前登录账户。如果模型在该智能体中也不可用，请先更新或重新配置它。

## 无法使用回退

停止正在执行的任务，并确认该任务属于 Git 项目。只有当前智能体能够安全回退到对话中的相应位置时，才会显示 **回退到这里**。**从此处派生任务** 始终是不影响原任务的备选方案。

## 更改语言或主题

打开 **设置 → 外观**，可选择英语、简体中文、跟随系统、浅色或深色。文档的语言切换位于侧边栏底部。

<Callout title="按 ⌘K 快速找到所需内容">
  命令面板可在同一处搜索任务标题、消息、项目、设置和命令。
</Callout>
