## 审阅文件更改

点击回复中文件更改摘要旁的 **查看**，或按 `⌘⇧B` 打开右侧面板，再选择 **审阅**。

在来源选择器中，可以查看上一轮、全部未提交更改、未暂存或已暂存更改、已提交内容，以及当前分支。选择文件即可阅读差异；需要更多背景时，可展开未修改的行。

## 从某条回复派生任务

如果想尝试另一个方向，又不想影响原任务，可在智能体回复上使用 **从此处派生任务**。Waku 会新建一个独立任务，并保留截至该回复的对话。

这很适合比较两种方案，或让另一个模型接手其中一条思路。

## 回到较早的提示词

在 Git 项目中，可在较早的提示词上使用 **回退到这里**；如果界面提供 **编辑**，也可直接使用。Waku 会将项目恢复到该提示词发送前的状态，并从当前任务中移除之后的对话。

回退前：

1. 停止正在执行的任务。
2. 审阅或提交希望保留的工作。
3. 选择目标提示词并确认，再发送修订后的请求。

只有当 Waku 能够同时安全对齐项目状态和当前智能体的对话时，才会显示这个操作。如果不可用，请派生新任务，或改用你平时的 Git 工作流程。

<Callout type="warn" title="回退会改变工作树">
  请把它当作任何其他回滚操作对待：先检查未提交的工作，尤其是在 Waku 之外完成的修改。
</Callout>
