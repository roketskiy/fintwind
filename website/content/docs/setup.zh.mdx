## 安装 Waku

Waku 目前支持 Apple 芯片 Mac。

1. 从 [waku.sh](https://waku.sh) 下载最新版本。
2. 打开磁盘映像，将 Waku 移入 **应用程序**。
3. 打开 Waku。以后可通过更新提示，或 **Waku → 检查更新…** 安装新版本。

## 连接编程智能体

Waku 支持 Amp、Claude Code、Codex、Cursor、OpenCode、Grok 和 Pi。

<Steps>
  <Step>
    ### 安装并登录

    按照官方说明安装智能体的命令行程序，然后在终端中完成一次登录。Waku 会沿用这个账户。
  </Step>
  <Step>
    ### 检查识别状态

    打开 **Waku → 设置… → 模型服务商**。连接成功后，这里会显示可执行文件的位置和可用模型。
  </Step>
  <Step>
    ### 必要时指定安装位置

    如果 Waku 没有找到某个智能体，请在 **可执行文件路径** 中选择相应程序，并按 Return 应用。清空此字段即可恢复自动识别。
  </Step>
</Steps>

## 打开项目

按 `⌘O` 并选择项目文件夹。项目会出现在侧边栏中，下次打开 Waku 时仍然可用。

<Callout type="info" title="数据的去向">
  项目、任务和设置保存在这台 Mac 上。提示词和你选择的上下文会通过当前智能体发送，因此相应服务商的账户与数据政策仍然适用。
</Callout>
