Press `⌘N` to start a new task. Waku keeps a separate draft for each project, including any files or images you attached.

## Choose the task's context

Before sending the first message, use the controls below the composer:

- **Project** — where the agent should work. Choose **Don't work in a project** for general questions or tasks outside a repository.
- **Model** — select any model reported by a connected agent. Star models you want to keep near the top.
- **Build / Plan** — use **Build** when changes are expected and **Plan** when you only want inspection and a proposed approach.
- **Access** — decide which actions can proceed without asking.
- **Workspace and branch** — work in the local checkout or isolate the task in a new worktree.

## Give useful context

- Drag files or folders onto the composer to attach them.
- Paste a screenshot or copied Finder file.
- Type `@` to find and mention a project file.
- Type `/` at the start of a line to use available commands and skills.

Remove an attachment chip before sending if it is no longer relevant.

## Write the request

A compact prompt usually needs three things: the outcome, any constraints, and how you want the result checked.

> Add keyboard navigation to the settings list. Keep the existing visual design, follow macOS conventions, and run the focused tests when done.

You can refine the request while the agent is working; you do not need to put every detail in the first message.
