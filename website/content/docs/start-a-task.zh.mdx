---
title: 开始任务
description: 发送前，为任务选择合适的项目、模型和工作方式。
---

按 `⌘N` 开始新任务。Waku 会为每个项目分别保留草稿，其中也包括已添加的文件和图片。

## 选择任务上下文

发送第一条消息前，可通过输入框下方的控件进行设置：

- **项目**：智能体要在哪里工作。普通问答或不需要代码仓库的任务，可选择 **不使用项目**。
- **模型**：选择任一已连接智能体提供的模型。为常用模型加星后，即可固定在列表前部。
- **构建 / 计划**：需要修改时选 **构建**；只需检查并提出方案时选 **计划**。
- **访问权限**：决定哪些操作可以无需询问直接进行。
- **工作位置与分支**：在本地检出中工作，或用新工作树隔离任务。

## 提供有用的上下文

- 将文件或文件夹拖到输入框中即可添加。
- 粘贴截图，或从 Finder 复制的文件。
- 输入 `@` 搜索并提及项目文件。
- 在行首输入 `/` 使用可用的命令和技能。

如果某个附件不再相关，可在发送前从附件标签中移除。

## 写下请求

一条简洁的提示词通常只需说明三件事：期望结果、必须遵守的限制，以及如何检查结果。

> 为设置列表添加键盘导航。保持现有视觉设计，遵循 macOS 交互习惯，完成后运行相关测试。

智能体工作时仍可继续补充要求；无需在第一条消息中塞进所有细节。
